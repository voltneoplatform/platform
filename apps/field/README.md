# Field App (milestone M5)

React Native (Expo), Android first. Used by field agents, technicians and
recovery staff for onboarding, KYC capture, cash receipts, installation, service
and recovery. It signs in through the same staff OTP API as the admin panel
(app clients receive the refresh token in the response body and store it in
secure device storage).

Not started yet: see the Platform MVP Spec V1, milestone M5.
